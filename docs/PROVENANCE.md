# Artifact provenance

This repository packages the Silent Influence research implementation and retained results
for public inspection. Presentation changes do not constitute new experiments.

## What is preserved

Experimental configurations, answer records, annotation records, result tables,
and numerical summaries are copied from the retained research package. Task records are
also preserved except for the credential redactions described below. Original research
artifacts remain separate from this working release. The vendored Jacobian Lens remains
under its own Apache-2.0 license with its executed revision and file hashes recorded.

The original research layout is retained for the code, silence analysis, and mechanistic
pipeline. Some historical paths and field names refer to earlier stages; the code guide
explains the important distinctions rather than silently redefining the records.

## What the public presentation adds

- A reader-oriented README and methods, results, and code guides.
- Standard-library examples that inspect recorded results and render an exact prompt diff.
- Repository diagrams and charts generated from the saved evidence.
- A release-level checksum verifier, explicit manifest builder, tests, and CPU CI workflow.
- Presentation-only wording updates in a small number of document and figure-builder
  comments. Numerical result records are not edited for presentation. Benchmark text has
  the limited privacy redactions below.

The historical test report is documented separately from checks performed for this release.
Historical model execution is not being attributed to the creation date of this repository.

## Graphics

All README graphics are generated by [`tools/build_assets.py`](../tools/build_assets.py).
The quantitative panels read the final behavioral result and the retained mechanistic
summary. The example panel reads the MT-Bench 101 record and checks its answer hash.
The hero and study-design panels are explanatory illustrations, not additional data.

The matched example was selected after examining outcomes. Its scores are real, but its
selection does not support a prevalence claim. The existing raster assets in
[`figures/paper_exact/`](../figures/paper_exact/) have their own provenance. Regenerating
the new repository graphics is not a claim to regenerate those earlier rasters.

## Integrity and exclusions

### Credential redactions in earlier task pools

Two credential-like strings in WildBench task `4e291c89184a4817` are replaced with explicit
redaction markers in four public prompt-pool files. The task is absent from the final
234-task scoring manifest and merged final behavioral records. Final scoring inputs,
outputs, estimates, and figures are unchanged.

[`PUBLIC_REDACTIONS.json`](../PUBLIC_REDACTIONS.json) records the affected files, original
and public file hashes, and replacement markers. Original research files and historical
freeze records are unchanged. The older freeze hashes intentionally do not match the four
redacted public files; the historical full-workspace integrity gate cannot establish byte
identity for them. No original credential values are included in the redaction record.

The canonical-task preflight loader accepts the historical manifest hash or the exact
documented public hash. It independently checks the canonical question's bytes against
the original question hash and records which manifest variant was used. Unrecognized
file changes still fail. The original full-workspace freeze-chain checker is unchanged.

### Release inventory

`ARTIFACT_MANIFEST.json` describes this release's files, sizes, and SHA-256 values. It is a
new release inventory rather than a claim that this repository is byte-identical to a
previous package. `verify_package.py` checks the inventory and recorded-result consistency;
it does not change the manifest. Local environments, generated outputs, caches, and Git
metadata are excluded.

Raw multi-gigabyte tensors, model weights, the fitted lens tensor, some historical working
records, and runtime environments are outside the release. [OMISSIONS.md](../OMISSIONS.md)
identifies those boundaries. Inspecting the shipped derived-contrast outputs is possible;
independently recomputing them from raw tensors requires those omitted source tensors.

Public benchmark inputs and model responses are experimental records. References to tools,
institutions, or people inside those inputs are task content, not project authorship or
development statements. Third-party source files retain their required notices.
